# Operator synopses

When Wikipedia's plot section for a queued film is thin (fewer than 250 words) the run records a
`kind: skipped` row in `ledger.json` and moves on. Write the synopsis here as `<slug>.md`
(slug = lower-case title, non-alphanumerics → `-`, then `-<year>`, e.g. `memento-2000.md`),
300–700 words, neutral, present tense, the whole story including the ending, nothing invented.
An optional first line `Lead: <director, year, main cast>` gives the planner context.
The next run takes the film again.
