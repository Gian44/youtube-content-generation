Privacy policy

Last updated 7 October 2026

The "sleeponfacts" application is an automated publishing tool used by the owner of the Sleep On Facts YouTube channel to upload videos to that one channel. It is not offered to the public as a service, and it does not collect information about viewers of the channel.

What Google data the app uses

Through Google's OAuth consent, the channel owner grants the app permission to upload videos, set thumbnails and read basic channel details on the YouTube account they choose. The app uses that permission only to publish the videos it generates. It does not read comments, subscriber lists, watch history or any other data about other people.

How credentials are stored

The OAuth refresh token is stored as an encrypted secret in the channel owner's own GitHub Actions configuration and is used only inside those scheduled jobs. It is never written to the public source code, logs or any third-party service.

Sharing

No Google user data is sold, shared or transferred to anyone. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from myaccount.google.com/permissions, which immediately stops the app from uploading.
